# سِنِت (Senet) — APK

1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `senet`).
2. ارفع كل محتويات هذا المجلد كما هي (بما فيها مجلد `.github`).
3. من تبويب Actions شغّل «Build Android APK» (أو يعمل تلقائيًا عند الرفع).
4. بعد نجاحه (دقيقتان تقريبًا) افتح التشغيل وحمّل `senet-apk` من Artifacts، ثم فكّ الضغط وثبّت `app-debug.apk`.
